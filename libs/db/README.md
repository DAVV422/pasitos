# @pasitos/db

Esquema de Drizzle, migraciones, aislamiento por organización con RLS (`withOrganizacion()`, D47) y semillas. Los tests `*.int.spec.ts` levantan PostgreSQL con Testcontainers (requieren Docker).

## Comandos

| Comando | Qué hace |
|---|---|
| `nx test db` | Tests |
| `nx lint db` | Lint |
