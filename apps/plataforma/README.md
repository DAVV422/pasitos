# Consola de plataforma (`/plataforma`)

Para el equipo de Pasitos: organizaciones, mensajes de contacto y salud del sistema.

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve plataforma` | Servidor de desarrollo |
| `nx build plataforma` | Build de producción |
| `nx test plataforma` | Tests |
| `nx lint plataforma` | Lint |
