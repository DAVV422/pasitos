# Pantalla de sala o stand (`/sala`)

Tablet o monitor que muestra el QR firmado del reto que toca según la agenda.

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve sala` | Servidor de desarrollo |
| `nx build sala` | Build de producción |
| `nx test sala` | Tests |
| `nx lint sala` | Lint |
