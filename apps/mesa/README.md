# Mesa de canje (`/mesa`)

Tablet o celular que cobra canjes con un QR y muestra el comprobante confirmado.

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve mesa` | Servidor de desarrollo |
| `nx build mesa` | Build de producción |
| `nx test mesa` | Tests |
| `nx lint mesa` | Lint |
