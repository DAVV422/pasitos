# API (`/api/v1`)

NestJS sobre Fastify. Logs con `traceId`, errores en formato Problem Details, Sentry y `GET /api/v1/salud`. Lee `.env` (ver `.env.example`).

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve api` | Arranca en desarrollo (lee `.env`) |
| `nx build api` | Build de producción |
| `nx test api` | Tests |
| `nx lint api` | Lint |
