# App del asistente (`/app`)

El asistente, desde su celular: vincula su navegador, gana puntos escaneando QR y los canjea. Presupuesto: ≤ 250 KB comprimidos en la primera carga.

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve app` | Servidor de desarrollo |
| `nx build app` | Build de producción |
| `nx test app` | Tests |
| `nx lint app` | Lint |
