# Sitio público (`/`)

Landing, *Eventos* y página de cada evento, con Angular SSR. Necesita Node 24.15 o superior para compilar (prerender).

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve sitio` | Servidor de desarrollo |
| `nx build sitio` | Build de producción |
| `nx test sitio` | Tests |
| `nx lint sitio` | Lint |
