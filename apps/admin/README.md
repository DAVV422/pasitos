# Panel del organizador (`/admin`)

Preparar el evento, la vista Puerta del registrador, el seguimiento en vivo y el cierre. En desarrollo, `/admin/_ui` muestra el catálogo del design system.

## Comandos

| Comando | Qué hace |
|---|---|
| `nx serve admin` | Servidor de desarrollo |
| `nx build admin` | Build de producción |
| `nx test admin` | Tests |
| `nx lint admin` | Lint |
