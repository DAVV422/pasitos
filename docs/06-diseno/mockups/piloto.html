Decisiones de diseño

  • La vista Puerta es una sola pantalla con prioridades fijas: avisos, buscar, escanear, registrar. Todo se usa con una mano.
  • El estado de cada invitado siempre combina color y texto (Invitada, Vinculado, Presente).
  • Ningún mensaje muestra IP ni huella del dispositivo; solo el modelo y el navegador.
  • El código de asistente usa siempre tipografía monoespaciada (A-0231), para leerlo en voz alta sin confundir caracteres.
